## Complete Project-Based Course

**Institution:** University of London / Goldsmiths  
**Module Code:** CM1005  
**Duration:** 20 weeks  
**Credits:** 30 (UK Level 4)  
**Primary Language:** JavaScript  
**Graphics Library:** p5.js  
**Learning Approach:** Project-based learning  

---

## 📚 Course Overview

This complete beginner-friendly course teaches programming from scratch using JavaScript and p5.js. You'll build a progressive **Space Explorer** game, learning one concept at a time and immediately applying it to your growing project.

### What You'll Build

**Space Explorer** - A 2D interactive game where you:
- Control a spaceship on a canvas
- Collect stars and avoid asteroids
- Track your score and lives
- Implement game logic with conditionals
- Manage multiple objects with arrays and loops
- Organize code with functions
- Create game entities with objects and constructors

### Learning Philosophy

✅ **One concept at a time** - Learn progressively  
✅ **Immediate application** - Apply each concept to your game  
✅ **Project-based** - Build one game that grows each week  
✅ **Beginner-friendly** - No prior programming experience needed  
✅ **Free resources** - All materials are freely available

## 📅 20-Week Schedule

### Phase 1: Foundations (Weeks 1-6)

| Week | Topic | Key Concepts | Project Milestone |
|------|-------|--------------|-------------------|
| 1 | Development Environment | Setup, p5.js basics, setup() and draw() | Create first canvas with basic shapes |
| 2 | Drawing in 2D | Coordinates, shapes, colors, styles | Draw a space scene background |
| 3 | Variables & Data Types | Variables, numbers, strings, booleans | Add a stationary spaceship |
| 4 | Interaction | Mouse/keyboard input, built-in variables | Make the spaceship respond to input |
| 5 | Objects & Properties | Object literals, properties, methods | Create a Player object |
| 6 | Conditionals | if/else, comparison operators, logic | Add boundary checking and collision |

### Phase 2: Core Programming (Weeks 7-12)

| Week | Topic | Key Concepts | Project Milestone |
|------|-------|--------------|-------------------|
| 7 | Arrays Basics | Array creation, indexing, length | Store multiple stars |
| 8 | For Loops | Loop syntax, iteration, counters | Draw multiple stars with a loop |
| 9 | Array Traversal | Looping through arrays, accessing elements | Update all stars in the game |
| 10 | Nested Loops | Loops within loops, 2D patterns | Create a starfield background |
| 11 | Functions Basics | Function declaration, parameters, calling | Create helper functions |
| 12 | Functions Advanced | Return values, scope, refactoring | Refactor game into functions |

### Phase 3: Advanced Concepts (Weeks 13-18)

| Week | Topic | Key Concepts | Project Milestone |
|------|-------|--------------|-------------------|
| 13 | 2D Arrays | Arrays of arrays, grids, matrices | Create a grid-based level |
| 14 | Array Methods | push(), splice(), search algorithms | Manage dynamic game objects |
| 15 | Object Methods | Methods, this keyword, behavior | Add methods to Player object |
| 16 | p5.Vector | Vector math, position, velocity | Implement smooth movement |
| 17 | Multiple Objects | Arrays of objects, object management | Create Enemy and Collectible objects |
| 18 | Object Interaction | Collision detection, object relationships | Implement game mechanics |

### Phase 4: Object-Oriented Programming (Weeks 19-20)

| Week | Topic | Key Concepts | Project Milestone |
|------|-------|--------------|-------------------|
| 19 | Constructor Functions | Constructors, this, object creation | Create entity constructors |
| 20 | Final Project | Integration, polish, testing | Complete Space Explorer game |

## 🎮 The Space Explorer Project

### Week-by-Week Evolution

**Week 1-2:** Empty canvas → Space background  
**Week 3-4:** Stationary ship → Moving ship  
**Week 5-6:** Ship with boundaries → Collision detection  
**Week 7-8:** Multiple stars → Animated starfield  
**Week 9-10:** Dynamic stars → Complex patterns  
**Week 11-12:** Helper functions → Clean, organized code  
**Week 13-14:** Grid levels → Dynamic object management  
**Week 15-16:** Player methods → Smooth vector movement  
**Week 17-18:** Enemies & collectibles → Full game mechanics  
**Week 19-20:** Constructor functions → Complete, polished game  

### Final Game Features

✅ Player-controlled spaceship  
✅ Multiple collectible stars  
✅ Obstacles and enemies  
✅ Score tracking  
✅ Lives system  
✅ Start and game over screens  
✅ Collision detection  
✅ Smooth movement with vectors  
✅ Multiple object types  
✅ Clean, organized code

## 📖 How to Use This Course

### For Each Week:

1. **Read the lesson** (`week-XX/lesson.md`)
   - Learn the concepts
   - Study the examples
   - Understand the theory

2. **Complete exercises** (`week-XX/exercises.md`)
   - Practice the concepts
   - Build confidence
   - Test your understanding

3. **Work on the project** (`week-XX/project.md`)
   - Apply concepts to your game
   - Follow step-by-step instructions
   - Test your implementation

4. **Take the assessment** (`week-XX/assessment.md`)
   - Check your understanding
   - Identify areas for review
   - Prepare for next week

5. **Review and consolidate** (`week-XX/review.md`)
   - Summarize what you learned
   - Review key terminology
   - Preview next week

### Recommended Study Schedule

- **3-4 hours per week**
- 1 hour: Read lesson
- 1 hour: Complete exercises
- 1-2 hours: Work on project
- 30 minutes: Assessment and review
