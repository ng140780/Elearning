### **Lesson Content Format**

Lessons use markdown-like syntax with support for:
- Headings (# ## ###)
- Code blocks (```)
- Lists (- and numbered)
- Bold (**text**)
- Links and images (framework ready)

### **Example Lesson:**

```markdown
# Bubble Sort

## Algorithm

Repeatedly step through the list, compare adjacent elements...

## Implementation

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr
```

## Complexity

- **Time**: O(n²) worst and average case
- **Space**: O(1) - in-place sorting
```
