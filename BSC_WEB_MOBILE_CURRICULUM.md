# BSc Computer Science — Web & Mobile Development Specialism

## Complete 3-Year Curriculum Specification

**Institution:** University of London (Goldsmiths)  
**Degree:** BSc Computer Science  
**Specialism:** Web & Mobile Development  
**Duration:** 3 years (full-time equivalent)  
**Total Credits:** 360 credits  
**Total Modules:** 22 taught modules + 1 final-year project

---

## Important Notes

**Source Attribution:**
- This curriculum is **based on** the official University of London BSc Computer Science program
- Module codes and names are taken from the REPL repository (https://github.com/world-class/REPL)
- **Credit allocations for Year 3 are PROPOSED** and not necessarily the official Goldsmiths structure
- The official degree uses 30-credit modules in Year 3; this specification uses 10-credit taught modules + 60-credit project for finer granularity
- All learning resources are free and publicly available
- This curriculum is designed for independent self-study

**Web & Mobile Development Focus:**
This specialism emphasizes:
- Full-stack web application development
- Cross-platform mobile development
- Modern JavaScript/TypeScript ecosystems
- Cloud deployment and DevOps
- Applied AI integration in web/mobile apps
- User experience and interface design

---

## Credit Structure

### Year 1 — Foundations (120 credits)
- 8 modules × 15 credits = 120 credits
- Focus: Programming fundamentals, computer science theory, web basics

### Year 2 — Intermediate Development (120 credits)
- 8 modules × 15 credits = 120 credits
- Focus: Advanced programming, full-stack development, mobile foundations

### Year 3 — Advanced & Professional (120 credits)
- 6 taught modules × 10 credits = 60 credits
- 1 final project × 60 credits = 60 credits
- Focus: Advanced topics, specialization, capstone project

**Total: 360 credits**

## Technology Stack Progression

### Year 1
- **Python**: Programming fundamentals
- **HTML/CSS/JavaScript**: Web basics
- **SQL**: Database fundamentals
- **Git**: Version control
- **Linux**: Command line

### Year 2
- **TypeScript**: Type-safe development
- **React**: Modern frontend framework
- **Node.js/Express**: Backend development
- **PostgreSQL**: Advanced databases
- **REST APIs**: API design
- **React Native**: Mobile foundations

### Year 3
- **Next.js**: Advanced React framework
- **React Native/Expo**: Cross-platform mobile
- **Docker**: Containerization
- **AWS/Vercel**: Cloud deployment
- **AI APIs**: OpenAI, Anthropic, etc.
- **CI/CD**: Automated deployment
