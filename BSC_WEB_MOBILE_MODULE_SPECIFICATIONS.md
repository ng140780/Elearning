## Module 1: CM1005 — Introduction to Programming I

**Year:** 1 | **Semester:** Fall | **Credits:** 15  
**Prerequisites:** None  
**Estimated Study Hours:** 150 hours (30 hours/week × 5 weeks contact + 120 hours independent)

### Module Description
An introduction to programming using Python. Covers computational thinking, basic programming constructs, and problem-solving techniques. Students will learn to write, test, and debug simple programs.

### Learning Outcomes
On successful completion, students will be able to:
1. Apply computational thinking to decompose problems
2. Write Python programs using variables, data types, and operators
3. Implement control flow (conditionals and loops)
4. Define and use functions with parameters and return values
5. Work with basic data structures (lists, dictionaries)
6. Read from and write to files
7. Debug programs using systematic techniques
8. Write well-documented, maintainable code

### 12-Week Syllabus

**Week 1: Introduction to Programming & Computational Thinking**
- What is programming? Problem-solving approach
- Setting up Python environment (VS Code, Python interpreter)
- First program: Hello World
- Computational thinking: decomposition, pattern recognition, abstraction, algorithms
- **Exercise:** Write a program that asks for user's name and age, then calculates birth year

**Week 2: Variables, Data Types & Operators**
- Variables and naming conventions
- Data types: int, float, str, bool
- Arithmetic operators: +, -, *, /, //, %, **
- Comparison operators: ==, !=, <, >, <=, >=
- Logical operators: and, or, not
- Type conversion and casting
- **Exercise:** Build a simple calculator that performs basic arithmetic operations

**Week 3: Input/Output & String Manipulation**
- Input function and type conversion
- Print formatting: f-strings, format()
- String methods: upper(), lower(), strip(), split(), join()
- String slicing and indexing
- **Exercise:** Create a text analyzer that counts words, characters, and vowels

**Week 4: Conditional Statements**
- if, elif, else statements
- Nested conditionals
- Boolean expressions and truth tables
- Short-circuit evaluation
- **Exercise:** Build a grading system that converts numerical scores to letter grades

**Week 5: Loops — while and for**
- while loops and loop control
- for loops with range()
- Iterating over sequences
- break, continue, pass statements
- Nested loops
- **Exercise:** Create a number guessing game with limited attempts

**Week 6: Functions — Part 1**
- Defining functions with def
- Parameters and arguments
- Return values
- Function documentation (docstrings)
- Scope: local vs global variables
- **Exercise:** Write utility functions for temperature conversion, factorial calculation

**Week 7: Functions — Part 2 & Modules**
- Default parameters and keyword arguments
- Variable-length arguments (*args, **kwargs)
- Lambda functions
- Importing modules (math, random, datetime)
- Creating custom modules
- **Exercise:** Build a module of mathematical utility functions

**Week 8: Data Structures — Lists**
- Creating and accessing lists
- List methods: append(), extend(), insert(), remove(), pop()
- List slicing and indexing
- List comprehensions
- Iterating over lists
- **Exercise:** Implement a to-do list manager with add, remove, display functions

**Week 9: Data Structures — Dictionaries & Tuples**
- Dictionary creation and access
- Dictionary methods: keys(), values(), items(), get()
- Nested dictionaries
- Tuples and immutability
- Sets and set operations
- **Exercise:** Build a contact book with search and update functionality

**Week 10: File I/O**
- Opening files with open()
- Reading files: read(), readline(), readlines()
- Writing files: write(), writelines()
- File modes: r, w, a, r+
- Context managers (with statement)
- CSV file handling
- **Exercise:** Create a program that reads student data from CSV and calculates averages

**Week 11: Error Handling & Debugging**
- Common error types: SyntaxError, TypeError, ValueError, IndexError
- try-except blocks
- Raising exceptions
- Debugging techniques: print statements, debugger, IDE tools
- Reading and understanding tracebacks
- **Exercise:** Add error handling to previous programs; debug provided buggy code

**Week 12: Introduction to Object-Oriented Programming & Review**
- Classes and objects basics
- Attributes and methods
- __init__ constructor
- Review of all topics
- **Project:** Personal Productivity Console Application

### Practical Programming Exercises
1. **Week 1-3:** Basic programs (calculator, text analyzer, unit converter)
2. **Week 4-5:** Control flow programs (grading system, number games, pattern printing)
3. **Week 6-7:** Function libraries (math utilities, string processors)
4. **Week 8-9:** Data structure applications (to-do list, contact book, inventory system)
5. **Week 10-11:** File processing (CSV analyzer, log parser, data validator)
6. **Week 12:** OOP basics (student management system)

### Major Project: Personal Productivity Console Application

**Requirements:**
Build a command-line productivity application with the following features:
- User authentication (simple username/password stored in file)
- Task management: add, remove, update, display tasks
- Task categories and priorities
- Due dates and reminders
- Search and filter functionality
- Data persistence (save/load to JSON or CSV files)
- Statistics and reporting (completed tasks, productivity metrics)
- Error handling and input validation
- Well-documented code with functions and classes

**Deliverables:**
- Source code with proper structure
- README with installation and usage instructions
- Sample data files
- Demonstration video or live demo

## Module 2: CM1015 — Computational Mathematics

**Year:** 1 | **Semester:** Fall | **Credits:** 15  
**Prerequisites:** None  
**Estimated Study Hours:** 150 hours

### Module Description
Mathematical foundations for computer science including discrete mathematics, logic, probability, statistics, and linear algebra. Emphasis on practical applications using Python.

### Learning Outcomes
On successful completion, students will be able to:
1. Apply set theory, relations, and functions
2. Use propositional and predicate logic
3. Perform combinatorial calculations
4. Understand probability distributions and statistical analysis
5. Apply linear algebra concepts (vectors, matrices)
6. Use mathematical notation and proof techniques
7. Implement mathematical algorithms in Python
8. Apply mathematical concepts to computer science problems

### 12-Week Syllabus

**Week 1: Sets, Relations & Functions**
- Set notation and operations
- Venn diagrams
- Relations and properties (reflexive, symmetric, transitive)
- Functions: injective, surjective, bijective
- **Exercise:** Implement set operations in Python

**Week 2: Logic — Propositional**
- Propositions and truth values
- Logical operators: AND, OR, NOT, IMPLIES, IFF
- Truth tables
- Logical equivalence
- **Exercise:** Build a truth table generator

**Week 3: Logic — Predicate & Proof Techniques**
- Predicate logic and quantifiers (∀, ∃)
- Proof techniques: direct, contradiction, induction
- **Exercise:** Write simple proofs; implement logical validators

**Week 4: Boolean Algebra & Digital Logic**
- Boolean expressions and simplification
- De Morgan's laws
- Logic gates
- Binary representation
- **Exercise:** Build a boolean expression evaluator

**Week 5: Number Systems & Binary**
- Binary, octal, hexadecimal systems
- Conversion between bases
- Binary arithmetic
- Bitwise operations
- **Exercise:** Implement base conversion and bitwise operations

**Week 6: Combinatorics**
- Counting principles
- Permutations and combinations
- Binomial theorem
- Pigeonhole principle
- **Exercise:** Solve combinatorial problems; implement combination generators

**Week 7: Graph Theory Basics**
- Graph definitions and terminology
- Graph representations (adjacency matrix, list)
- Graph traversal (BFS, DFS)
- **Exercise:** Implement graph data structures and traversal algorithms

**Week 8: Probability Fundamentals**
- Sample spaces and events
- Probability axioms
- Conditional probability
- Bayes' theorem
- **Exercise:** Calculate probabilities; simulate probability experiments

**Week 9: Probability Distributions**
- Discrete distributions: Bernoulli, Binomial, Poisson
- Continuous distributions: Uniform, Normal
- Expected value and variance
- **Exercise:** Implement distribution functions; analyze data

**Week 10: Statistics — Descriptive**
- Measures of central tendency: mean, median, mode
- Measures of dispersion: variance, standard deviation
- Data visualization
- **Exercise:** Statistical analysis of datasets using Python

**Week 11: Linear Algebra — Vectors & Matrices**
- Vector operations
- Matrix operations: addition, multiplication
- Determinants and inverses
- **Exercise:** Implement matrix operations; solve linear systems

**Week 12: Applications & Review**
- Applications to computer science
- Review of all topics
- **Project:** Mathematical Toolkit Library

### Practical Programming Exercises
1. Set operations and relation checker
2. Truth table generator and logic validator
3. Base converter and bitwise operation tool
4. Combinatorial problem solver
5. Graph implementation and traversal
6. Probability simulator
7. Statistical analyzer
8. Matrix operations library

### Major Project: Mathematical Toolkit Library

**Requirements:**
Build a Python library implementing mathematical concepts:
- Set operations module
- Logic and boolean algebra module
- Graph theory module (representations, traversal)
- Probability and statistics module
- Linear algebra module (vectors, matrices)

**Deliverables:**

- **Complexity**: Equivalent to a production-ready application

1. **Frontend**: React/Next.js with TypeScript
